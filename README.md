# Clarity Business

**Clarity Business（清晰经营）** 是一款面向小微商户的轻量销售数据看板。上传 CSV 或 Excel 销售明细，在浏览器里查看销售额、订单、月度趋势、商品和客户排名，并下载分析报告。

> 当前版本使用固定统计规则，不调用大语言模型，也没有接入任何 AI 服务。页面中的“经营提示”是基于表格数据的规则提示，不是 AI 判断、审计结论或经营建议。

## 快速开始

下载或克隆本项目，双击 `index.html` 即可使用。也可以通过任意静态文件服务器预览；项目没有构建步骤、包管理器或后端服务。

页面打开后会展示一组虚构的示例销售数据。点击“上传销售数据”选择自己的 `.csv`、`.xlsx` 或 `.xls` 文件，确认自动识别的列对应关系，再点击“生成经营分析”。所有数据都留在当前浏览器内存中，页面不会将销售文件或分析结果发送到本项目的服务器，也不会将数据写入浏览器存储。关闭或刷新页面后，导入的数据会清除。

## 支持的数据格式

- 文件：CSV、XLSX、XLS、XLSM（仅读取工作表数据，不运行宏）。
- 第一张工作表 / CSV 第一行需要是列名；默认只分析第一张工作表。
- 日期和销售额是必需列。订单号、商品、客户、数量、成本、利润为可选列。
- 中英文常见列名会自动匹配；上传后可在确认面板中手动修改映射。下拉选项同时显示友好中英字段名称和原始表头，分析仍按原始列位置读取。
- 可按全部数据、最近 3 / 6 / 12 个月筛选，也可指定开始和结束日期；筛选会同步更新指标、图表、排名、提示和导出。快捷月份以数据中的最新日期为截止日期。
- 支持常见日期写法（如 `2025-01-31`、`2025/1/31`、`2025年1月31日`）和常见带货币符号、千位分隔符的数字。
- 文件上限为 25 MB，记录上限为 200,000 行。无效日期或销售额的行会被跳过，并在界面提示数量。

使用 `sample-sales.csv` 可以体验导入流程。该样例为虚构数据。

## 指标口径

- **销售额**：有效记录的销售额相加；负数记录会计入总额，并单独提示可能是退款或冲销。
- **订单数**：订单号去重计数；没有订单号的记录按每行一单处理。多行商品明细可以属于同一订单。
- **平均订单金额**：销售额合计除以订单数。
- **利润**：优先使用利润列；没有利润值时，如果提供成本则按“该行销售额 − 该行成本”计算。成本应是该行的总成本，而不是单位成本。只有每条有效记录都能得到利润时才显示完整利润总额与利润率。
- **商品 / 客户排名**：按相应名称分组后，累加销售额；空名称不参与该维度排名。
- **月度趋势**：按日期所在月份汇总。销售额变化比较最近两个有记录的月份，未按自然日数校正。
- **金额偏高提示**：将销售额高于“第三四分位数 + 1.5 × 四分位距”的记录列出，供人工复核。数据量较少时该规则不稳定。

所有提示都只是辅助检查；异常不一定意味着错误，规则未触发也不代表没有问题。结果受原始数据、列映射、退款记录和记账口径影响。

## 隐私与第三方组件

CSV 由本地 JavaScript 读取和分析。上传 Excel 文件时，应用会按需从 SheetJS 官方 CDN 加载 SheetJS Community Edition 0.20.3，然后在本机浏览器中解析文件。Excel 文件内容不会发送给 CDN；但首次处理 Excel 需要联网下载该解析脚本。若网络不可用，可将 Excel 另存为 CSV 后使用。

应用没有账号、分析后端、遥测或持久化存储。请仍按你所在组织的规则处理敏感业务数据，并使用可信设备和浏览器。

## 下载结果

- **下载分析报告**：生成独立 HTML 报告，含关键指标、月度汇总、商品 / 客户排名和规则提示，可在浏览器打开或打印为 PDF。
- **导出汇总 CSV**：导出关键指标、月度销售额 / 利润和前十商品 / 客户汇总。

## 语言与后续扩展

页面顶部提供简体中文和 English 切换。当前仅开放这两种已完成的语言；西班牙语、俄语、法语、德语和日语尚未加入可选列表，也不会显示机器翻译或未完成内容。切换语言会同步更新看板、图表、导入提示和下载报告 / CSV 的列标题；用户上传的商品名、客户名和文件名保留原样。示例商品和客户名会随界面语言显示对应译文。

翻译集中在 `locales.js`。增加语言时，为 `window.CLARITY_LOCALES` 添加完整目录，覆盖页面文案、错误和状态、报告 / CSV 文案、字段匹配别名、示例商品 / 客户名、日期格式单位；然后将该语言代码加入 `APP_LOCALES`。只有完整翻译并核对所有界面和导出内容后，才把语言加入可选列表。语言列表刻意与翻译目录分开控制，避免未完成语言提前发布。英语帮助文档为 `README.en.md`。

## 部署到 GitHub Pages

1. 在 GitHub 登录后点击右上角 **+ → New repository**，创建一个新仓库（例如 `clarity-business`）。是否公开由你决定。
2. 在仓库页面选择 **Add file → Upload files**，上传本项目中的全部文件和 `sample-sales.csv`，保持 `index.html` 位于仓库根目录，然后提交更改。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 下将来源设为 **Deploy from a branch**，选择 `main` 分支和 `/(root)` 文件夹，点击 **Save**。
5. 等待 Pages 部署完成，GitHub 会在 Pages 设置区域显示网址。项目通常可通过 `https://你的用户名.github.io/仓库名/` 访问。

更新网页时，将修改后的文件再次提交到 `main`。可在 GitHub 仓库页面打开 **Add file → Upload files** 上传更新文件并提交，也可以在已有 Git 仓库中运行 `git add .`、`git commit -m "Add Chinese and English localization"` 和 `git push origin main`。首次发布和后续部署可能需要几分钟生效。GitHub Pages 网站会公开显示在互联网上，即使仓库本身设为私有也可能如此；不要把客户数据、账号凭据或私人销售表格提交到仓库。完整的发布源设置说明见 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 兼容性与已知限制

- 面向近期版本的 Chrome、Edge、Firefox 和 Safari；需要支持现代 JavaScript、`File`、`Blob` 与下载链接的浏览器。
- Excel 解析脚本仅在选取 Excel 文件时联网加载；CSV 导入和示例演示不依赖该脚本。
- 仅读取 Excel 文件的第一张工作表；不读取公式定义、图表、透视表、隐藏元数据，也不重新计算 Excel 公式。
- 当前是单页本地看板，不提供账户、多用户协作、云端保存、税务核算或库存管理。
- 中文日期 / 数字格式以常见写法为主；复杂的多行表头、合并单元格、多个币种和自定义记账规则需要先在表格软件中整理。
